# CreatHive

> **“Built for the limitless Creatives...”**  
> A mobile-first Progressive Web App (PWA) designed for creatives to showcase multi-discipline portfolios, capture performance opportunities, and manage their creative assets with unlimited freedom.

---

## 🌟 The Vision

Initiated in response to the **UNICEF / Generation Unlimited Nigeria (GenU 9JA) 2026–27 Young People's Action Team (YPAT)** creative talent showcase call:
> *"If you’re into spoken word, poetry, music, dance, or any other creative field, please share about what you do alongside the link to the sample of your work."*

Instead of fragmented Google Drive links or lost email attachments, **CreatHive** provides an instant, distraction-free stage designed for sensory, visual, and performance art.

---

## ✨ Features

- **🎙️ Spoken Word & Audio Streaming:** Tactile audio player with kinetic pulsing waveforms and synchronized read-along script drawers.
- **💃 Dance & Performance Reels:** High-resolution vertical and widescreen video showcases with ambient previews.
- **✍️ Substack-Grade Poetry Reader:** Literary typography (`Newsreader` serif) and distraction-free reader mode that gives poems the prestige they deserve.
- **🎨 Tech Imagery & UI/UX Design:** Mobile interface walkthroughs, 3D Afro-futurist renders, and visual design carousels without code syntax clutter.
- **⚡ Kinetic Neo-Editorial UI:** Warm paper canvas (`#FDFBF7`), soft-brutalist buttons with spring physics, and `@phosphor-icons/react` duotone SVGs (zero generic emojis).
- **📱 True Progressive Web App (PWA):** Installable on iOS & Android (`manifest.json`), offline-ready shell, safe-area-inset native ergonomics.
- **🎯 Conversion Funnel & Booking:** Direct "Book for Gig / Performance" inquiry modal, instant applause counters with confetti bursts, and native web share.
- **🛠️ Creator Studio:** Unlimited management access to publish, edit, and track portfolio conversions.

---

## 🚀 Tech Stack

- **Framework:** Next.js 16+ (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **State & Data Caching:** TanStack Query (React Query v5)
- **Animations:** Framer Motion (spring physics, layout morphs)
- **Icons:** Phosphor Icons (`@phosphor-icons/react` Duotone & Bold)
- **Effects:** Canvas Confetti

## 🛠️ Getting Started

```bash
# Clone the repository
git clone https://github.com/SalamBhai/CreatHive.git
cd CreatHive

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser (or `http://localhost:3000/sheriff` to view the YPAT showcase profile).
